## 做了什么

**资产（全部脚本生成，生成后逐件渲染预览图检查）**
- **调色板扩容**：256 色（256×512，原来 128 色已经用满）。新增武器贴纸色、沙色、金色、指示灯、分区地面色等。
- **18 把枪**：统一加细节层——抛壳窗（露出黄铜弹壳）、螺丝、散热槽、背带环、侧面贴纸和仓鼠爪印贴纸、警示条纹；**每把枪顶面都有识别色**（俯视角主要看顶面：冲锋枪薄荷绿顶条、轻机枪警示条纹、加特林黄黑条纹、反器材沙色机匣、榴弹黄色弹带……）。批次 1 的手枪、AK、霰弹枪也补了同样的细节，免得反而比新枪简陋。
- **13 种道具 + 投掷物**：燃烧瓶（火焰标签、布条、火苗）、闪光弹（出光孔一圈）、地雷（黄黑警示带、触发针）、自动炮台（护罩、摄像头、天线、弹箱）、护盾手腕（六边形发射器、指示灯）、烟雾弹（云朵贴花）、照明弹、诱饵仓鼠（腮红、小手、接缝）、喷气背包（尾翼、压力表）、急救包（拉链、提手、一小堆瓜子）、冰冻手雷（雪花、冰刺）、传送信标（小屏幕）、手雷（菠萝纹）。
- **野怪 / 鼠王 / 宠物**：蟑螂（油亮高光条、腿刺、口器）；持枪老鼠（斜挎弹带、腰带、耳朵缺口、脸上的疤、鼓弹匣冲锋枪）；鼠王（大王冠 + 红丝绒内帽 + 宝石、貂皮领、红绶带、金链勋章、**单独摆动的斗篷**、金色鼓弹匣枪）；宠物都戴**队伍色小围巾**（看得出是谁的宠物）。
- **鼠王出场演出**：从天而降 → 落地压扁回弹 + 金色冲击环 + 落地轰响 → 王冠转一圈。斗篷走路时往后飘、站着随呼吸轻摆。
- **建筑三阶段破损**（血量 66% / 33% / 摧毁）：
  - 炮台：轻损 = 凹痕、撕开的标签、顶盖焦痕和交叉胶带；重损 = 顶盖破洞翘起铁皮、露出电线、炮塔头也破洞冒弹簧；摧毁 = 压扁的罐头 + 掉下来的炮塔头 + 散落的瓶盖。
  - 鼠窝：轻损 = 胶带补丁、凹痕、屋顶掀角、瓜子壳；重损 = 墙上破洞、毛巾屋顶撕开、毛巾滑落、窗户破；摧毁 = 塌成一堆纸板 + 毛巾 + 倒下的旗。
  - 每掉一个阶段：碎片 + 尘土 + 一声金属响；重损时冒黑烟、偶尔冒火花；摧毁时大团尘土和碎片四散，废墟冒一阵细烟。
- **小兵**：头盔顶十字条纹 + 铆钉（俯视角一眼看出是兵）、下巴带、背包队伍色灯和天线、腰带。
