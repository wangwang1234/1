# 满载而鼠 0.3.7 · 局域网联机试玩版

本版整合批次 1～3、导演反馈第一至三轮、画面升级第一至六轮及 0.3.7-lan7 局域网联机，包含：

- 局域网房间：完整地图最多 10 人（5 对 5），中路小图最多 6 人；附近房间发现、自由分队、准备与开始、AI 补齐空位、短暂掉线自动重连及超时 AI 接管。
- 开放 10 把武器及右键 / E 专属技能、Tab 比分板、黑暗视野、画面个性化，以及此前的 AI、武器平衡、进化和成长调整。
- 验证后修复：低帧率角色挤压 / 后坐弹簧发散、场景挂接期间失焦创建暂停菜单的竞态。

下载后解压整个顶层文件夹 `满载而鼠_0.3.7`，Windows 双击 `manzai.exe`，Mac 双击 `满载而鼠.app`。两包均附说明、AI 观战、双人分屏与帧率测试入口。

macOS 为 Intel / Apple Silicon 通用版，采用临时签名，未公证；首次打开方法见随包说明。联机要求同一局域网及相同版本，完整地图 10 人房主上行约 18 Mbps。

自动验证通过：官方 Godot 4.7.2-stable，145 项 sim 零失败，全量末行“全部通过”，15 项 LAN 回归全通过。云端软件 Vulkan 双窗口加载曾出现客户端掉线，真实右键与 Tab 的双窗口操作尚未完成验收；跨电脑 Wi-Fi、Windows / macOS 真机联机及目标 GPU 性能仍需实机检查。详见 `review/verify_merge/REPORT.md`。
