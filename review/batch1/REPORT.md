## 怎么玩

- **Windows 包**：仓库里的 `release/manzai_batch1_win64.zip`（46 MB），解压后进 `满载而鼠_批次1` 文件夹双击 `manzai.exe`（单文件，资源都打包在里面）。同目录有 `帧率测试.bat`、`AI观战.bat`、`说明.txt`。Windows 可能提示“未知发布者”，点“更多信息 → 仍要运行”（没有代码签名证书，批次 5 处理）。
- 操作：WASD 移动，鼠标瞄准，左键射击，空格翻滚，R 换弹，Q 手雷，1/2/3 选升级卡，Esc 暂停。手柄：左摇杆移动、右摇杆瞄准、RT 射击、A 翻滚、X 换弹、LB 手雷、X/Y/B 选卡。
- 主菜单右下角可以换皮肤，也可以选初始武器（试玩用，方便直接对比三把枪的手感；正式规则是手枪起步）。
- 一局：3 对 3（你 + 2 个 AI 队友 对 3 个 AI）。先拆对面的中路炮台，对面鼠窝的护盾才会消失，再拆鼠窝获胜。第 5 分钟进入“加速决战”（建筑受双倍伤害、小兵变强、AI 改为优先拆建筑）。AI 对 AI 一般 10～20 分钟分出胜负，你主动带兵推进会快很多。

## 做了什么

**1. 工程与工具链**
- Godot 4.7.2 工程（`game/`），git，命令脚本 `tools/run|test|capture|record|export|assets`（Linux `.sh` + Windows `.bat`）。
- Blender 资产管线：`tools/blender/build.py` + `lib/`（调色板、形体、骨骼、动画、导出、预览渲染），每个资产一个脚本，一条命令全部重建，自动出预览图。
- 音频管线：`tools/audio/build.py` 用 numpy / scipy 合成 39 种音效（大多 3–4 个变体，共 126 个 OGG），按原型的枪声配方。
- 截图 / 录屏 / 帧率测试：游戏自带 `--capture` 截图场景（风格帧、玩法序列、升级卡、进化配件、皮肤、暂停/结算、帧率），Movie Maker 录屏。
- Windows 导出：单文件 exe（资源打包进 exe），模板也是从源码编译的。

**2. 渲染**
- toon 着色器：2 阶明暗、窄柔化交界、冷紫环境光、点光 / 聚光做成分段光圈（台灯、手电落在地上是一圈一圈的卡通光斑）、角色边缘光（队伍色）、眼睛 / 金属硬高光、受击闪白、无敌闪烁。
- 描边：反向外壳，屏幕恒定线宽（角色约 2 px、物件约 1.5 px），用 Blender 里烘焙的平滑法线避免硬边断线。
- 夜晚：环境光压低，亮度来自手电（聚光 + 假体积光锥）、台灯、炮台和鼠窝的队伍色小灯、爆炸和枪口的临时光。
- 后处理：Filmic 色调映射、辉光、轻微饱和度 / 对比度。
- 镜头：俯角 56°、视野角 34°、横向始终看到 7.2 米；往准星方向前瞻、分级震屏、开火后坐；倒下后先停在原地 1.8 秒再移到鼠窝门口。参数已写回 ART_BIBLE 第 2 节。
- 特效：枪口焰（星形 + 拉长条 + 烟）、曳光、抛壳（弹壳落地有叮当声）、命中火花、墙面碎屑、卡通爆炸（烟团 + 冲击环 + 碎屑 + 焦痕）、死亡炸毛、伤害数字、升级星星、护盾六边形、拾取光环。粒子 / 弹壳 / 曳光 / 经验瓜子用 MultiMesh，伤害数字和临时光源用对象池。

**3. 主角仓鼠**
- 约 6.7k 三角面，体 / 头融合后重拓扑，眼睛 / 鼻子 / 胡须 / 腮帮 / 耳朵 / 针织帽（队伍色）/ 小爪。
- 4 种皮肤（金丝熊、布丁、银狐、三线）运行时切换；队伍色帽子运行时切换。
- 22 根骨骼（含武器 / 帽子 / 背 / 脸挂点），19 个动作：待机、四向跑、翻滚、受击、倒下、复活弹出、胜利、三种持枪 / 开火 / 换弹（手枪、步枪、霰弹枪）。
- 表情：睁眼、眯眼（开火）、眨眼、开心（升级 / 吃东西）、受伤、倒下；嘴：闭 / 张。
- 程序叠加：耳朵和尾巴弹簧、经验越多腮帮越鼓、移动挤压拉伸、开火后坐。

**4. 武器**
- 手枪 / AK-47 / 霰弹枪三个模型，每把 10 个挂点（7 个配件挂点 + 枪口 + 左右手）。
- 3 条进化路线 × 9 级的完整逻辑（数值全部写在 `evolutions.json` 的 `effects` 里），包括 9 级质变（扇射连发、三种弹轮换、压制火力、停顿首发翻倍穿透、火海、轰飞眩晕……）。
- 配件外观：路线第 3 级出现，第 6 级变大，第 9 级发光，颜色 = 路线色；“连点手指”加枪管金环，“强光手电 / 广角镜头”加大手电。
- 每把枪自己的枪口焰、抛壳、枪声（多变体 + 随机音高）、换弹声。

**5. 玩法（逻辑层 `scripts/sim/`，headless 可跑整局）**
- 移植原型：移动加速度、翻滚无敌帧、射击散布和伤害衰减、换弹、经验和升级、升级三选一（卡池 = 三把枪的进化 + 14 个通用强化 + 换武器卡，换武器只在三把枪之间）、Q 键手雷（默认道具）、复活、鼠窝旁回血。
- 小兵一条兵线（中路），每队一座中路炮台；中路炮台在时鼠窝有护盾。
- 视野：每队按手电光锥 + 近身 + 队友 / 小兵 / 建筑共享计算可见集合，看不见的敌人（连同他们的手电）直接隐藏。
- 听觉：枪声 / 爆炸 / 脚步 / 弹簧板产生声音，HUD 上画声波（屏幕内画涟漪，屏幕外在边缘画方向弧 + 距离）。
- 场景互动：零食箱 / 大礼箱（经验瓜子、奶酪回血）、爆炸罐（红色喷漆罐）、弹簧板、台灯（照亮一片区域，可打灭）、纸箱掩体（挡子弹视线，可打碎，60 秒复原）。
- AI：推线、挑目标、拆塔时保持距离、低血撤退回城、听到声音去侦察、自己选卡；人数占优或加速决战时主动拆建筑。
- 固定 60Hz 逻辑 + 渲染插值，带种子的随机数（同种子结果完全一致，有测试）。

**6. 地图切片**
- 用 `map_layout.json` 的中路带（全宽 50 米 × 10 米）：左边书房（木地板、书架、台灯）、中间客厅地毯、右边厨房（瓷砖）；书本墙、柜台、纸箱、瓶子、罐子、笔筒、弹簧板、零食箱位置、装饰散布（铅笔、橡皮、纽扣、瓜子壳、回形针……）。

**7. UI**
- 主题：圆角深紫面板、奶油色描边文字、强调橙 / 金；字体思源黑体 + 站酷快乐体（都是 OFL）。
- 主菜单（3D 展示台 + 皮肤 / 试玩武器选择 + 设置）、HUD（头像 + 经验环、血条、武器和弹药、进化路线进度点、强化徽章、手雷冷却、计时、比分条 + 炮台 / 护盾状态、下一波小兵倒计时、小地图、击杀播报、提示条、准星 + 换弹圈 + 命中标记、头顶血条和名字、射程圈、声波、受伤暗角）、升级卡（弹出动画、悬停放大、路线色条、角标、按键提示）、暂停（含操作说明）、设置（音量、特效强度、伤害数字、全屏，自动保存）、结算（战绩表）。
- 失去焦点自动暂停。

**8. 测试**
- `tools/test.sh`：28 项 sim 测试（数据、地图碰撞 / 视线 / 寻路、三把枪参数和伤害衰减、升级卡规则、切片和全图 2 分钟 AI 对局、确定性、36 种武器 × 进化等级组合、切片 AI 对局能分出胜负、换局不泄漏内存）+ 表现层 headless 跑 2 分钟 AI 对局（日志里不能有任何脚本错误）+ 主菜单冒烟。**全部通过。**

## 我替你做的决定

1. **Godot 用源码编译的 4.7.2**：云端容器下载不了官方安装包，git 可以，所以编辑器和 Windows 导出模板都是自己编译的。和官方 4.7.2 是同一份代码。
2. **切片范围**：ROADMAP 写的是“蓝方鼠窝一角 + 一段中路”。为了能“完整玩一小局”，我用了整条中路带（两边各一个鼠窝 + 各一座中路炮台，红方是镜像），并加了一条规则：**中路炮台在时，鼠窝有护盾**（全图版本里对应“三座外塔”）。
3. **切片的节奏调整**（只影响切片模式，数据在 `rules.json` 的 `match.slice`）：切片只有一条兵线、一座炮台，用原型的建筑血量 AI 对局 25 分钟都打不完（两边在中路对耗）。所以切片里炮台血量 ×0.6、鼠窝 ×0.4，第 5 分钟（全图是第 12 分钟）进入加速决战。另外给 AI 加了两条规则（全图也生效）：人数占优时没有小兵掩护也会去拆建筑；加速决战后以建筑为首要目标、只和贴近的敌人缠斗。
4. **镜头参数**：俯角 56°、视野角 34°、横向 7.2 米（原型约 6.4 米，PC 屏幕大一点所以略放宽）。已写回 ART_BIBLE。
5. **3 对 3**：切片对局是你 + 2 个 AI 对 3 个 AI（全图模式是 5 对 5）。
6. **主菜单可以选初始武器**：只是试玩方便，正式规则仍然是手枪起步，批次 2 做开局大厅时去掉。
7. **卡池**：天赋、宠物、道具卡本批不开；原本 10 / 20 / 30 级的天赋卡改成普通升级卡。换武器卡只在三把枪之间换。
8. **通用强化的外观**本批只做了 4 种（强壮 = 体型变大、顺风耳 = 耳朵变大、连点手指 = 枪管金环、强光手电 / 广角镜头 = 枪上大手电），其余强化的外观（ROADMAP 里的 22 种强化外观）在批次 3。
9. **看不见的敌人连手电一起隐藏**（和原型一致），所以黑暗里只能靠听觉和队友视野发现敌人。
10. **颜色调整**：中路地毯从紫色改成暗芥末色、厨房瓷砖压暗、鼠窝地毯改成中性深色 + 一圈队伍色（= 回血范围）——ART_BIBLE 要求“队伍色在任何场景里都要是最醒目的颜色”，紫地毯和亮蓝地毯会和蓝队抢色。
11. **装饰物**缩小、变稀：散布的文具原来太大太密，抢了仓鼠的视觉重心。
12. **手臂动画**用“橡皮管”式 IK（手臂可以轻微拉长去够枪），小兵用程序动画（没有骨骼），省面数也更 Q。
13. **数值**：原型里写死在代码里的常数全部搬进了新的 `game/data/rules.json`；进化效果写进 `evolutions.json` 的 `effects`（格式说明在 `_effectsDoc`）。
14. **音效全部自己合成**，没有用外部素材；本批只有环境底噪，没有音乐（批次 5）。
15. **字体**：思源黑体（正文）+ 站酷快乐体（标题、数字），都是 OFL 可商用。
16. **设置**保存在用户目录 `settings.cfg`；窗口失去焦点时自动暂停。
17. **Windows 包放进了 git**（`release/` 下的 zip，46 MB）：我这边的工具没法创建 GitHub Release。以后每批都放会让仓库变大，建议以后改用 GitHub Releases（你手动上传，或者给我相应的权限）。

## 已知问题

1. **帧率没法在这里测真实数据**：容器没有显卡，只有软件渲染（lavapipe），上面的帧率只能说明“逻辑和表现层的 CPU 开销”。**需要你在目标电脑上双击 `帧率测试.bat`（约 70 秒），把生成的 `perf` 文件夹发回来**，我按结果做性能优化。
2. **Windows 包没在真 Windows 上跑过**：容器里没有 Windows。我用同一份打包数据在 Linux 上 headless 跑过对局（资源、数据、音效都能正常加载），但窗口、显卡、声卡这部分要你实际双击确认。
3. **声音我听不到**：容器没有声卡，混音是按数值调的（录屏里测得整体平均 -21 dB、峰值 -1 dB），具体哪个声音偏大 / 偏小请试玩时留意。环境底噪每 8 秒循环一次，循环点有轻微的音量起伏。
4. **exe 图标是 Godot 默认图标**（改图标需要 rcedit，Linux 上没有；批次 5 做商店素材时一起处理）。
5. **手柄没有实机测试**（逻辑都接好了）。
6. **小兵**从俯视角看比较像“小圆帽子”，辨识度一般，批次 3 会重做得更有特点。
7. **AI 对 AI 的切片对局要 10～20 分钟才分出胜负**（两边实力对称，主要靠加速决战收尾）；截图和录屏都只有前两分半，`ui/result.png` 是用当时战绩模拟的结算画面。真人带兵推进应该明显更快，请试玩时感受一下节奏是否合适。
8. 退出游戏时 Godot 会打印“对象泄漏”的警告（退出时还有对象没释放），不影响游戏；换局时的泄漏已经修好并加了测试。
9. 16:9 以外的屏幕比例（超宽、4:3）没有专门检查 UI 布局。
10. **开局后 1～2 秒内立刻退出，在这台机器上会卡在退出流程里**（引擎退出时在等后台的着色器编译任务；软件渲染编译很慢才暴露出来）。正常游玩和正常退出都没问题，真显卡上编译快得多，影响应该很小；批次 5 打磨时再跟进（必要时开局加一个短暂的“着色器预热”）。
