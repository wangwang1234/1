# 满载而鼠：输入恢复与模型挂载修复

版本：0.3.8-fix1。基于 `codex/qol-pass1` 的 `ebaf127`；修复分支 `codex/focus-attachments`。

## 修复内容

- 点击窗口外 / 切屏后，清理可能缺失的键鼠松开事件；回到游戏自动恢复因失焦触发的暂停。手动暂停跨切屏仍保持暂停。
- 恢复操作只抑制实际按住的控制，第一次新按键不再被吞掉；恢复焦点的鼠标点击不转成射击。
- 联机失焦只停止本地操作，服务器继续运行；回到窗口恢复本地操作。
- 焦点通知遍历期间不直接添加暂停菜单，避免引擎报错；快速失焦—恢复—再次失焦不会被过期回调误恢复。
- 导入后同名骨骼自动改名为 `arm_R_2` 等。持枪动画筛选器匹配实际骨骼名称，恢复手臂、武器在移动和开火时的同步。
- 恢复此前找不到骨骼的耳朵、腮帮和尾巴程序动作。
- 鼠王王冠保留原始高度并挂到头部，跟随低头瞄准。移除每帧将王冠高度写到零附近的错误动画。
- 模型部件查找兼容 Blender 多资产生成造成的数字后缀，恢复鼠王枪、野怪身体 / 头 / 尾巴等部件动画。
- 小兵与鼠帮枪手的后坐力在原始枪位置上叠加，避免枪离开角色；小兵腿部动画保留脚底高度和前后偏移。

## 本批采用的决定

系统失焦引发的暂停在重新获得焦点时自动恢复；玩家主动打开的菜单需要主动继续。联机局不暂停服务器。保留原武器数值、成长、战斗规则及上一批改键和观战功能。

## 已知限制

- 交付源码、测试与审阅结果，没有重新导出 Windows/macOS 可执行包；旧安装包不会自行变更。
- 原生焦点验证来自 Linux/X11；仍需在 Windows/macOS 实机检查系统切屏、真实手柄及鼠标侧键。
- 部分 headless 测试退出仍有已有的资源引用残留提示，本批未宣称修复资源回收问题。
- 未合并默认分支其他玩法与画质改动，未宣称排除所有未覆盖的游戏 bug。
