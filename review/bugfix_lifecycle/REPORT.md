# 满载而鼠：第二轮 bug 排查

版本：0.3.8-fix2。基于上一轮输入恢复与武器挂载修复继续检查。

## 已复现并修复

| 问题 | 触发方式 | 修复后的行为 |
| --- | --- | --- |
| 复活首次操作漏按 | 翻滚、换弹或道具按下后死亡，在死亡期间松开，复活后再次按下 | 死亡期间继续更新按住状态并清理按键边沿；复活后的新按下立即生效 |
| 手柄连续升级漏按 | 第一轮用 X/Y/B 选卡，卡牌关闭时松开；下一轮按同一个按钮 | 没有卡牌时也观察按钮释放；三种按钮连续三轮均能选卡 |
| 键鼠接回后仍用手柄瞄准 | 用过手柄后，不移动鼠标，直接按键盘移动或射击 | 根据当前有效键鼠操作恢复鼠标瞄准和键鼠提示；键盘移动优先于手柄摇杆 |
| 混合输入右肩键不射击 | 单人默认键鼠兼容手柄模式下按右肩键 | 与纯手柄模式一样支持右肩键射击，并正确切换设备提示 |

## 我替你做的决定

死亡期间按住的翻滚等操作仍需松开再按，避免复活瞬间自动触发；在死亡期间已经松开的操作，不再吞掉复活后的第一次新按下。换弹按钮一直按住时，新出现的升级卡不会自动被选走。

本轮没有修改战斗数值、卡池或联网协议。
