# 方案：武器精简 + 右键技能（给导演商量）

## 一、武器精简

现在一共 18 把武器，其中好几组手感重叠：

| 类别 | 现有武器 | 问题 |
|---|---|---|
| 手枪类 | 手枪（起手）、沙漠之鹰、左轮手枪、双持手枪 | 4 把都是“单发、中射程”，靠伤害和射速区分，玩家感觉不出来；左轮在两档对局里胜率都垫底（14～27%） |
| 自动步枪类 | AK-47、冲锋枪、轻机枪、加特林 | 轻机枪夹在 AK 和加特林之间，没有自己的位置 |
| 霰弹类 | 霰弹枪、自动霰弹枪 | 只差射速，胜率都偏低（31～38%） |
| 精准类 | 狙击枪、反器材狙击枪、电磁炮 | 反器材狙和狙击几乎一样；电磁炮（穿透）有自己的特点 |
| 爆炸类 | 火箭筒、榴弹发射器 | 一个直射一个抛射，各有用途 |
| 独一份 | 武士刀（近战）、喷火器（喷射）、激光枪（持续光束） | 各自是独特的玩法 |

武器少了，每把的 3 条进化路线可以做得更深，模型、音效、特效也能各自精修。

### 方案 A：留 10 把（推荐）
每一把都是一种不一样的“打法”：

| 留下 | 打法 |
|---|---|
| 手枪 | 起手，不升级，尽快换掉 |
| 冲锋枪 | 近距离高射速、边跑边打 |
| AK-47 | 中距离万金油 |
| 加特林 | 站桩火力、开火要预热 |
| 霰弹枪 | 贴脸爆发 |
| 狙击枪 | 远距离一枪一个 |
| 火箭筒 | 范围爆炸、拆建筑 |
| 武士刀 | 近战冲刺、反弹子弹 |
| 喷火器 | 短程持续、点燃 |
| 激光枪 | 持续光束、弹射 |

去掉 8 把：沙漠之鹰、左轮手枪、双持手枪、轻机枪、自动霰弹枪、反器材狙击枪、电磁炮、榴弹发射器。

### 方案 B：留 12 把
在 A 的基础上，再留两把手感独特的：

- **榴弹发射器**：抛射、越过掩体；
- **电磁炮**：蓄力穿透一排。

### 方案 C：留 8 把（最精简）
在 A 的基础上，再去掉两把：

- **冲锋枪**：和 AK 合并成一把，AK 的进化里给一条“高射速”路线；
- **激光枪**：持续伤害的位置让给喷火器。

### 怎么去掉（不管选哪个方案都一样）
- 被去掉的武器不进卡池、不出现在开局大厅和图鉴里。
- 代码、模型和进化数据**先保留不删**，以后想加回来改一个开关就行（`rules.json` 的 `scope.weapons`）。
- 不影响已有的进化系统和测试。

## 二、右键技能

右键现在空着，适合放一个**主动技能**。下面三个方向，后两个可以组合。

### 方向 1：武器专属技能（推荐，和武器精简配套）
每把武器的右键是自己的“特殊一击”，冷却 8～12 秒：

| 武器 | 右键 |
|---|---|
| 手枪 | 快速连发 3 枪（起手武器也有点花样） |
| 冲锋枪 | 扫射：2 秒射速 +60% |
| AK-47 | 枪挂榴弹：打出一发小榴弹 |
| 加特林 | 瞬间满预热，并且 3 秒不耗子弹 |
| 霰弹枪 | 独头弹：一发远射程的重弹 |
| 狙击枪 | 标记射击：命中的敌人全队可见 4 秒 |
| 火箭筒 | 一次打出 3 发小火箭 |
| 武士刀 | 拔刀斩：向前冲刺一段，砍中路上所有敌人 |
| 喷火器 | 火墙：在前方留下一道燃烧带 |
| 激光枪 | 过载：一道粗光束，持续 1.5 秒 |

- **好处**：换武器的意义更大，每把枪更有个性；武器少了，每个技能都能精心做。
- **代价**：每把武器都要单独设计、做特效，留 10 把就是 10 个技能。

### 方向 2：手电聚焦（和黑暗玩法最搭）
按住右键，手电光束变窄、照得更远（约 +60%），被聚焦光束照到的敌人全队可见；聚焦时移速 -30%。手电有电量条，松开慢慢充回来。

- **好处**：只有一个机制，所有武器通用；直接强化“黑暗中找人”的核心玩法。
- **代价**：不是“爽快”的输出技能，更偏战术。

### 方向 3：道具挪到右键
现在 Q 键扔的战术道具（手雷、燃烧瓶、闪光弹……）改成右键瞄准投掷，Q 键空出来，以后放别的。

- **好处**：几乎不用新做内容；鼠标瞄准投掷比 Q 键更顺手。
- **代价**：没有增加新的玩法。

### 我的建议
- **右键 = 武器专属技能（方向 1）**，配合武器精简方案 A（10 把），先做 10 个技能。
- 如果你更想强调黑暗玩法，也可以选 **右键 = 手电聚焦（方向 2）**，再把武器专属技能放到别的键上。
