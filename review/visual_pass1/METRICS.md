# 固定机位绘制规模

1600×900，Forward+ / llvmpipe。数值为无 HUD 截图附近一帧的总绘制调用与提交图元，包含阴影绘制，不能当成模型自身面数或硬件 GPU 帧率。

| 区域 | 原版 draw calls | 修改后 draw calls | 原版提交图元 | 修改后提交图元 |
| --- | ---: | ---: | ---: | ---: |
| 书房 | 473 | 593 | 1,348,260 | 2,099,164 |
| 厨房 | 414 | 623 | 1,224,012 | 2,168,060 |
| 客厅 | 547 | 795 | 1,957,916 | 2,981,064 |

增加来自级联阴影、软阴影与更细的模型等。本轮还启用了 SSAO / SSIL；这些屏幕空间效果的成本也需要在目标 GPU 测量。不同视角会影响可见图元，以上仅供审阅。

原始数据保留在 before/ 与 final/ 的 *_metrics.json。
