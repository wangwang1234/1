# 画面升级第一轮

2026-10-10。基线：`05f651fda4475d188e0977e36cfc14d75c445879`。参考导演提供的三张《逃离鸭科夫》截图，以完成度、材质区分、光影体积与构图为目标，保留《满载而鼠》的仓鼠、夜间人类房子和三渲二风格。

## 实机画面审阅

书房、厨房、客厅、角色近景及 HUD 的前后对比通过开发会话的 `manzai_visual_review.zip` 交付。仓库中的 `visual` 截图脚本可复现这些画面，`tools/review_visual.py` 可从 before/ 和 final/ 的截图生成压缩图片、对比图和指标表。

截图来自实际地图与角色渲染，1600×900；基线和修改版使用同一采集脚本、种子 11、AK-47、角色朝向及站位。相机俯角属于本轮改动，56° 调整为 52°。静止审阅隐藏其他仓鼠，保留地图与灯具，不能代表多人交战时的特效密度。

## 已实现

- 灯光：保留表面的卡通明暗阶调，光源衰减与投射阴影改为连续变化；校正环境光、月光与暖光比例，降低自发光和泛光，加入 SSAO / SSIL。方向光使用近距离级联软阴影。
- 材质：木头、瓷砖、织物、装饰与角色采用独立参数；木头与织物加入低幅且按像素导数过滤的细节，瓷砖有克制的高光。地板取消描边，杂物减轻描边与边缘光。
- 模型：脚本重建木地板、瓷砖、地毯和陶盆。木地板薄缝错缝、少量木结；瓷砖缩窄缝隙；地毯改为稀疏织纹；陶盆有口沿、土壤、细碎石与多层绿叶。
- 场景：按七个分区配方成组摆放文具、食物、玩具等物件，减少无意义的随机撒点；检查整件物体的净空，避免掩体、弹射板、炮台和鼠窝被装饰侵占。
- 角色：减少自发光，调整边缘光和手电；修正 HUD 头像原本背对相机的问题，加入适合头像的独立灯光。
- 维护：画面参数集中到 `game/data/visual_style.json`，新增 `VisualStyle`；美术不消耗战斗随机数、不新增模拟碰撞。

## 性能与后续品质

实际绘制规模见 [指标](METRICS.md)。接触阴影、间接光、级联阴影和更精细模型会增加 GPU 开销。当前环境没有硬件 GPU，软件渲染耗时不能用于承诺目标电脑 60 FPS；应在目标设备用 `tools/capture.sh perf review/perf 1920x1080 --dur 60 --mode full` 测量平均帧率和 1% 低帧，再设画质档。

这一轮先改善渲染基础与材质层次，距离参考游戏的整体完成度仍有明显差距。下一阶段优先精修角色毛色与分件、帽子 / 装备材质、掩体与大型家具的轮廓和使用痕迹，再提高场景叙事密度，统一 UI 可读性、动画、特效，并做 LOD 与阴影成本优化。

## 复现

```bash
tools/assets.sh env_visual_kit
godot --headless --path game --import
tools/capture.sh visual review/visual_check 1600x900 --seed 11
tools/test.sh
```

单独用 Blender 生成时可加 `--no-preview`；全量资产构建时确保 `env_visual_kit` 在 `env_kit` 之后执行。保留现有物件模块名、地图比例、模拟障碍与玩法视野范围。
