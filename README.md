# 满载而鼠 — 正式版工程（交接包）

## 怎么开始
1. 把这个文件夹放到电脑上一个固定位置（路径里最好不要有空格）。
2. 安装：Godot 4（最新稳定版，标准版即可）、Blender 4.x、Python 3、Git。不确定的话，可以直接让 Claude Code 帮你检查缺什么。
3. 在这个文件夹里打开 Claude Code，第一句话说：**“读一下 CLAUDE.md，然后开始批次 1。”**

## 里面有什么
- `CLAUDE.md`：给 Claude Code 的工作规则（每次启动自动读取）
- `docs/`：设计文档、美术规范、管线规范、资产清单、里程碑、原型对照表
- `game/data/`：全部数值（武器、进化、道具、强化、天赋、宠物、单位、地图布局、成长）
- `reference/prototype/`：现在的可玩网页原型和源码
- `review/`：每个批次的审阅包会放在这里
