# 操作与观战体验：v0.3.7-qol1

基于 `codex/lan-v0.3.6`。同机、单人和局域网共用操作映射；本批未改变武器、成长路线与地图玩法。

## 自定义键位

设置 → 操作 → 选择玩家 1 或玩家 2 → 点击动作右侧按钮 → 按新键。支持键盘、鼠标左右/中键与两个侧键。冲突时会提示并继续等待；Esc 取消，Delete 恢复该动作默认；“恢复本组默认”恢复当前玩家的整套键位。设置立即保存，重启仍保留。Esc 始终能返回菜单，手柄 Start 也保留。

玩家 1 用于单人、联机及分屏第一位；玩家 2 的配置用于分屏键盘模式。两组键位独立；同机双人应避免共用同一个实体键。手柄仍使用原布局，当前未提供手柄改键。菜单帮助、开局帮助、卡牌标签和道具标签跟随实际键位。

## 死亡与观战

倒下后停留 1.2 秒，随后优先观战存活真人队友，再选择 AI 队友。默认玩家 1 用 `[` / `]`，玩家 2 用 `5` / `6`；手柄用十字键左右切换。手动切换可跳过死亡停留。

被观战者死亡或断线后自动选择其他己方队友；无可观战目标时回到己方基地附近并等待复活。复活自动切回自己。两队视野和渲染层保持原规则，不能借观战查看敌方视野；分屏只切换对应玩家的镜头。切换直接定位后恢复跟随，不横穿整张地图。

HUD 显示观战对象、复活倒计时、击败你的来源和切换提示。死亡来源由房主记录并随快照同步，重连或漏掉表现事件后仍可恢复。

## 菜单、声音、下一局

打开菜单立即清除移动、射击及一次性动作；关菜单有两帧保护，仍按住的键和手柄按钮须松开再按。联机时世界继续运行，菜单玩家停止输入。

声音仍分总音量、音效、音乐；新增可选的“切到后台静音”。回到前台按原音量恢复。

联机结算页双方都可“准备下一局”或取消准备。双方准备后自动返回原房间，保留昵称、队伍、地图及准备状态，由房主按“开始对局”。旧对局的准备消息会被拒绝。暂停菜单的“返回房间”仍保留原有手动返回行为。

## 验证命令

- `tools/test.sh`：原有回归、表现层冒烟及新增运行时回归。
- `godot --headless --path game -s res://tests/run_all.gd -- --only test_qol`：观战状态与死亡快照。
- `godot --headless --path game res://tests/qol_ui_smoke.tscn`：实际设置面板、按键轮询、保存、音频与分屏镜头。
- `python3 tools/test_qol_lan.py`：两个真实 ENet 进程连续三局。
- `QOL_REVIEW=<绝对输出目录> godot --path game --fixed-fps 60 res://tests/qol_ui_smoke.tscn`：设置及分屏观战截图，使用 Forward+。

版本签名包含本批版本及 qol 配置，两端应使用相同版本。跨 Windows/macOS 真机、侧键硬件和手柄体验仍需实测。

## 0.3.8-fix1 输入恢复

点击窗口外或切屏后，单机暂停；回到窗口自动继续。手动打开的暂停菜单跨切屏保持打开。联机对局继续运行，失焦期间只清空本地操作。恢复焦点的点击不会射击，未按住的新按键可立即使用；按住的控制需松开再按。
