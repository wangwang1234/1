# 满载而鼠 — 美术规范（Art Bible）

> 所有资产（模型、动画、贴图、特效、UI、图标）都由 Claude 用脚本生成。本文是统一风格的依据，生成任何资产前先对照本文。
> 品质目标：对标《逃离鸭科夫》的**完成度**（细节密度、灯光氛围、动画质感、UI 统一性、手感反馈），**不模仿它的画风和任何具体素材**。我们的风格是三渲二。

## 1. 场景主题（暂定，第一次审阅时由导演确认）
**夜晚的人类房子，仓鼠视角。** 仓鼠们在一间夜里熄了灯的屋子地板上打仗，周围全是按仓鼠比例放大的日常物件：纸箱、书本、积木、零食包装、易拉罐、电线、拖鞋、台灯、小夜灯。
- 这个主题和原型里已有的玩法物件天然契合：纸箱掩体、零食箱、可以打灭的灯、礼物盒（大礼箱）、经验瓜子。
- 分区建议：蓝队鼠窝在左（书房一角：书本、文具、台灯），红队鼠窝在右（厨房一角：瓷砖、调料瓶、饼干盒）；中路是客厅地毯；上路靠书架，下路靠沙发底；鼠王在上方中央（冰箱旁的阴影里），大礼箱在下方中央。
- 玩法物件的外观：爆炸桶 → 红色喷漆罐 / 打火机油罐；弹射装置 → 弹簧玩具板；灯 → 台灯 / 小夜灯；零食箱 → 零食包装盒；大礼箱 → 系丝带的礼物盒。

## 2. 镜头
- 俯视斜角跟随（沿用原型）。批次 1 定下的参数（代码在 `game/scripts/view/game_camera.gd`）：
  - 俯角 52°（从水平面往下看，2026-10 画面升级第一轮从 56° 调整，参数在 `visual_style.json`），垂直视野角 34°（长焦一点，透视不夸张）。
  - 镜头距离按屏幕宽度自动算：**画面横向始终看到 7.2 米**（原型约 6.4 米；仓鼠高约 0.45 米，1080p 下画面里约 80 像素高）。宽屏 / 窄屏只改变上下能看到多少。
  - 跟随：往准星方向前瞻（鼠标 = 准星点和角色连线的 18%，最多 1.6 米；手柄 = 朝向前方 0.5 米），平滑系数 7；死亡后镜头慢慢移到己方鼠窝。
  - 震屏用 trauma²（开火、受击、爆炸、击杀分级），另有开火方向的后坐偏移；地图边缘夹紧，不拍到地图外。
- 设计任何资产都先从游戏镜头角度看剪影：**从上往下看，顶面信息最重要**——帽子颜色、武器轮廓、配件必须从这个角度一眼可读。

## 3. 三渲二规则
- **明暗**：亮 / 暗阶调定义大形，少量连续漫反射补充圆脸与倒角的体积。阶调只作用于表面朝向；光源衰减与投射阴影保持连续，不量化成扇形光圈。
- **阴影色**：不是把固有色压黑，而是往冷紫偏（夜晚氛围），保持饱和度。
- **描边**：反向外壳法（inverted hull）。基准线宽按屏幕恒定，1080p 下角色约 2 px、场景物件约 1.5 px；实际强度按材质配置缩放，地板不描边、装饰更轻；线色是固有色压暗，不用纯黑。
- **边缘光**：角色和可交互物件有一圈边缘光（暖白或队伍色），保证在黑暗里能看清轮廓。
- **高光**：眼睛、金属、玻璃保留克制的卡通高光，混入连续镜面反射；瓷砖可有低强度宽高光，木头与织物保持哑光。
- **材质**：以调色板贴图的平涂色块为主；细节靠模型的倒角、分件和少量贴花（贴纸、文字、磨损、污渍），不靠写实贴图。
- **落地与构图**：接触阴影体现角色和物件与地面的关系；杂物按分区成组靠近掩体，保留行走、弹射板、炮台与鼠窝的净空。参数集中在 `game/data/visual_style.json`。

## 4. 色彩
- 队伍：蓝 `#4fa3ff`、红 `#ff5b5b`、中立 `#ffd166`。队伍色只用在帽子、旗帜、建筑灯带、曳光、UI，保证一眼分队。
- 进化路线：A 橙 `#ff9a3c`、B 蓝 `#5fb0ff`、C 紫 `#c77dff`。
- UI：奶油白 `#fff3e0`、深紫底 `#1a1226`、强调金 `#ffd166`；卡片类型色：进化 `#ff9a3c`、强化 `#5fb0ff`、道具 `#c77dff`、天赋 `#ff6fd0`、宠物 `#5fd38a`、换武器 `#d9d4e2`。
- 场景：底色是深蓝紫的夜色；光源偏暖（手电暖白、台灯暖黄）；爆炸和火焰用高饱和橙黄。**队伍色在任何场景里都要是最醒目的颜色。**

## 5. 角色：仓鼠
- **比例**：大头 Q 版，头和身体差不多大；眼睛很大（占脸宽 30% 以上），两点高光；圆鼓鼓的腮帮；短手短脚、小尾巴。
- **帽子**：队伍色毛线帽 + 绒球。顶视角面积最大，是分队的第一识别点。
- **4 种皮肤**：金丝熊（毛色 `#f2a54a`）、布丁（`#f7d37c`）、银狐（`#e4e1ea`）、三线（`#b2adbd`，背上一条深色条纹 `#5e5868`）。肚子和脸下半部是奶油色。
- **表情**：平时眨眼；开火时眯眼；受伤 `>_<`；死亡 `×_×`；升级和胜利时开心。眼睛和嘴做成可切换的贴花或形变。
- **动作风格**：弹性夸张（挤压拉伸、跟随、回弹），关键姿势清楚，可以带一点动画式的“停顿感”。
- **强化外观**（22 种，详见 GDD 第 9 节）：
  - 体型：强壮（每级大一圈）。
  - 身上：防弹背心（护甲）、弹药带（击杀回弹）、工具腰包（道具大师）、背上磁铁（大磁铁）、背上特斯拉线圈（连锁闪电）、背后小旗（战旗，队伍色）、运动鞋（风火轮）。
  - 头上：眼镜（学霸）、夜视仪（夜视仪）、天线（侦察兵）、红头巾（越战越勇）、四叶草（幸运瓜子）、小獠牙（吸血）、耳朵变大（顺风耳）。
  - 枪上：更大的手电（强光手电、广角镜头）、枪口结冰（冰霜弹）、金色枪管环（连点手指）。
  - 特效：绿色光点（再生）、翻滚残影（翻滚大师）、脚下绿色光环（治疗光环）。
  - 多个外观同时出现时不能互相穿插，位置要错开（背后三件：磁铁偏左、线圈偏右、旗子居中偏上）。

## 6. 武器
- 现代真实枪械的**玩具化版本**：比例加粗 1.2～1.4 倍，细节归纳成大块面和清楚的分件，从顶视角能认出是哪把枪。
- 金属用深灰（不是纯黑），配合木头、塑料、贴纸等点缀色；每把枪有一个识别色块。
- **进化配件**：8 类（瞄准镜、枪口装置、弹鼓、侧挂罐、线圈、雷达盘、战术手电、武士刀刀身光），颜色用路线色。路线第 3 级出现，第 6 级变大，第 9 级发光。每把枪的模型里预留配件挂点。
- 道具外观：手雷、燃烧瓶、闪光弹、地雷、自动炮台、能量护盾（手腕发生器 + 六边形护罩）、烟雾弹、照明弹、诱饵仓鼠（充气玩具仓鼠，带气门嘴）、喷气背包（装备时背在身上）、急救瓜子包、冰冻手雷、传送信标。

## 7. 其他单位
- **小兵**：队伍色的小号仓鼠兵，比玩家小一圈，戴统一头盔，好认、好批量。
- **炮台 / 鼠窝**：用屋子里的物件改造（例如罐头改的炮塔、纸箱和毛巾搭的鼠窝），带队伍色灯带；被拆时有分阶段破损。
- **野怪**：蟑螂（小、快、成群、油亮的背壳）、持枪老鼠（比仓鼠大、凶）、鼠王（Boss，大号、戴王冠、有出场演出）。
- **宠物**：小鸡战友、萤火虫、刺猬炮台。

## 8. 特效语言
- 统一三渲二：硬边、少渐变、色块分层，必要时加深色边缘。
- 枪口焰按武器区分大小和形状；曳光用队伍色；弹壳落地有反弹。
- 命中火花、爆炸（卡通烟团 + 冲击环 + 碎屑）、火焰（卡通火舌）、电（青色锯齿）、冰（淡蓝晶体）、毒气（绿色）、护盾（六边形）、传送（青色光柱）、升级（路线色星星）。
- 震屏和顿帧分级：普通命中 < 暴击 < 爆炸 < 击杀 Boss。

## 9. UI
- 圆角面板、奶油色文字、深紫半透明底；游戏内文字一律带描边，保证在任何背景上可读。
- 字体：只用可商用的开源字体（例如思源黑体，SIL OFL 授权）；授权文件放进工程。
- 图标：从 3D 模型直接渲染（统一 3/4 视角、带描边、透明底），保证和游戏内模型一致。
- 卡片：类型色标签 + 图标 + 名称 + 效果描述；**不显示等级数字**。
