# 原创程序生成贴图

- `study_window.png`、`gobo_window_plant.png`、`gobo_blinds.png`、`gobo_table_chairs.png`、`gobo_fridge_wedge.png`：本项目原创聚光灯投影纹理（窗框、龟背竹叶、百叶窗、餐桌椅、冰箱门缝），由 `tools/build_gobos.py` 用 Pillow 生成；没有使用《逃离鸭科夫》素材。
- `decals.png`：本项目原创地面贴花图集（咖啡杯印、果汁渍、灰尘里的袜子脚印等），由 `tools/build_decals.py` 用 Pillow + numpy 生成。
- `palette.png`：项目原有脚本生成调色板。
